# Contributing to Mirro

Mirro is an archived research/reference project. Contributions are welcome when they improve documentation, reproducibility, Android-version compatibility research, sanitized diagnostics, tests or safe experimental code.

Please include:

- the research question and architecture area;
- Android version, OEM/device and target app version when relevant;
- sanitized logs and a clear failure category;
- tests and reproducibility steps;
- license/provenance confirmation for copied or adapted code.

Do not submit features for Play Integrity bypass, DRM bypass, signature/UID spoofing, credential or session extraction, anti-tamper bypass, or app-specific evasion. Do not post tokens, cookies, account data, private logs, device serials or proprietary APKs.

See [SECURITY.md](SECURITY.md) for security reporting and the repository templates for required evidence.
